# kru-siwakorn

เว็บประจำตัวครูศิวกร แก้ววีด (โรงเรียนสาธิตมหาวิทยาลัยวลัยลักษณ์) สำหรับนักเรียน: รายวิชา สื่อการสอน เครื่องมือ และข้อมูลครู

สร้างด้วย Next.js ไม่มีฐานข้อมูล เนื้อหาทั้งหมดอยู่ในไฟล์ของ repo นี้

## แก้เนื้อหา

| ต้องการแก้ | ไฟล์ |
|---|---|
| รายวิชา หน่วยการเรียนรู้ หัวข้อรายสัปดาห์ | `src/data/courses.json` |
| รายการสื่อ เครื่องมือ ข้อมูลครู อีเมล | `src/data/site.ts` |
| สี ขนาดตัวอักษร การจัดวาง | `src/app/globals.css` |

## เพิ่มสื่อการสอน 1 ชุด

1. วางไฟล์ PDF ที่ `public/media/<slug>.pdf`
2. แปลงแต่ละหน้าเป็นรูป `public/media/<slug>/1.jpg`, `2.jpg`, ... (กว้าง 1400px)
3. เพิ่มรายการใน `media` ที่ `src/data/site.ts` (ใส่ `slug`, ชื่อ, วิชา, จำนวนหน้า)

## รันบนเครื่อง

```
npm install
npm run dev
```

## Deploy

Import repo นี้ใน Vercel ได้เลย ไม่ต้องตั้งค่า Environment Variables
